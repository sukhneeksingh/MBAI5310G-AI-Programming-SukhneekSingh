# Assignment 4(b): Urban Fleet Decision Tree Analysis

## Overview
This assignment focuses on building and analyzing a **Decision Tree model** for the UrbanFleet delivery service to predict delivery delays and assess business risk.

## Project Objective
Develop a machine learning solution to:
- Predict delivery delays using a Decision Tree classifier
- Analyze factors impacting delivery performance
- Provide business recommendations based on model insights

## Contents

### 📓 Jupyter Notebook
- **`Assignment 4_UrbanFleet_DecisionTree_Assignment.ipynb`**
  - Complete implementation of the Decision Tree analysis
  - Data exploration and preprocessing
  - Model training and evaluation
  - Visualization of decision trees and feature importance
  - Performance metrics and insights

### 📊 Dataset
- **`urbanfleet_delivery_delay_risk_dataset.xlsx`**
  - Raw data containing delivery records
  - Features related to delivery characteristics
  - Target variable: delivery delay classification
  - Used for model training and validation

### 📄 Business Plan
- **`urbanfleet_delivery_delay_business_plan.docx`**
  - Business context and problem statement
  - Data analysis findings
  - Recommendations and action plans
  - Executive summary

## Key Concepts Covered

- **Decision Trees**: Understanding tree-based classification models
- **Feature Importance**: Identifying key factors affecting delivery delays
- **Model Evaluation**: Using metrics like accuracy, precision, recall, and F1-score
- **Hyperparameter Tuning**: Optimizing tree depth, min_samples_split, etc.
- **Business Intelligence**: Translating model insights into actionable recommendations

## How to Use

1. **Review the Data**: Start by examining `urbanfleet_delivery_delay_risk_dataset.xlsx` to understand the dataset structure
2. **Run the Notebook**: Execute `Assignment 4_UrbanFleet_DecisionTree_Assignment.ipynb` in Jupyter or any compatible environment
3. **Analyze Results**: Review visualizations, model performance, and feature importance rankings
4. **Read Business Plan**: Consult the business plan document for strategic recommendations
